TL;DR L3G-World couples L3G-Mem and L3G-Gen to generate consistent worlds over long horizons. Its 3D memory grows adaptively with explored scene extent, while direct rendering into the diffusion latent space enables real-time generation.

Adaptive Memory Update

L3G-Mem spawns compact Gaussians for newly explored regions and refines existing ones on revisits. Memory grows with scene extent rather than the number of generated frames, allowing GPU memory use to level off during repeated exploration.

Direct Latent Rendering

Each Gaussian stores VAE latents that render directly into the diffusion latent space, bypassing RGB rendering and VAE re-encoding. Fast memory update and rendering enable real-time generation with few-step distillation.

Consistent World Generation

L3G-Mem updates the persistent 3D memory from each generated video chunk. L3G-Gen then uses that memory to condition subsequent chunk generation. This closed loop preserves a consistent world throughout long-horizon exploration.

Abstract

Interactive world models generate visual content conditioned on user actions, yet maintaining spatial consistency over long-horizon exploration in real time remains challenging. Existing approaches rely on either temporal context or explicit 3D memory, both of which scale poorly because memory grows with the length of the generated stream. Moreover, explicit 3D memories condition latent video generators by re-encoding RGB renderings, which precludes real-time generation. In this paper, we introduce a Latent 3D Gaussian Memory (L3G) that combines the efficiency of feed-forward reconstruction with a compact, rapidly renderable scene representation. Building on this memory, we propose L3G-World, in which a memory updater and a video diffusion transformer (DiT) alternate autoregressively to generate spatially consistent worlds. The memory updater spawns Gaussians in newly observed regions and refines existing ones, so that the memory grows with scene extent rather than stream length. Each Gaussian further stores a VAE latent feature, allowing the memory to be rendered directly into the DiT's latent space without VAE re-encoding. Experiments show that L3G-World achieves state-of-the-art generation quality and long-horizon spatial consistency, with up to 38.6× fewer 3D primitives, 3.2× faster memory updates, and 359× faster memory rendering relative to the most efficient prior 3D-memory baseline for each metric, enabling real-time world generation at 9 FPS.

Methodology

L3G-Mem

L3G-Mem reconstructs compact 3D Gaussian memory from observed or generated views. It spawns Gaussians in newly observed regions and refines existing geometry and features as new views arrive. Each Gaussian stores a VAE feature for direct latent rendering.

Adaptive Memory Update

L3G-Mem adds Gaussians where the current memory lacks coverage and refines existing Gaussians as new observations arrive. Selective spawning avoids redundant primitives, while residual refinement corrects geometry instead of preserving its errors. Together, they improve reconstruction quality with a compact memory that grows with the explored scene.

Latent 3D Gaussian Memory

Each Gaussian stores a VAE latent feature, so the memory renders directly into the video generator’s conditioning space. This removes the RGB-rendering and VAE-encoding round trip. In the L3G-Mem ablation, direct latent rendering reaches 943.6 FPS compared with 2.97 FPS without VAE lifting, while also improving latent reconstruction quality.
